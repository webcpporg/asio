== Changelog

Changes prepared for the first WebCPP release.

[#asio-changelog-unreleased]
=== Unreleased

// tag::unreleased[]
* *Breaking change:* Removed `/webcpp/asio//cobalt` and `cobalt_ssl`; link `/webcpp/cobalt//cobalt` or `cobalt_ssl`.
* Fixed browser turn budgets across timer waits so worker proxy messages can run.
* Fixed browser and WASIp2 timer test dependencies and the unbounded backend control.
* Improved exception analysis of system executor initialization without changing fatal behavior.
* Fixed posted completions after JavaScript reentry with concurrency hint one.
* Added current example coverage and Release performance, memory and yield measurements.
// end::unreleased[]

[#asio-changelog-0-1-0]
=== webcpp 0.1.0

// tag::0.1.0[]
* Added Boost.Asio contexts and timers with browser event-loop suspension.
* Added browser workers, main-thread handoff and turns defaulting to 100 handlers.
* Added Promise and DOM-event operations with cancellation and allocator support.
* Added browser socket adapters, retained resolver names and TLS settings.
* Added WASIp2/P3 networking, UDP gather/scatter and asynchronous forward DNS.
* Added Cobalt, CLI streams, WASI TLS and P3 cooperative-thread integration.
* Added optional source-built OpenSSL and replaceable embedded CA certificates.
* Fixed Cobalt TLS state/cancellation and TLS error equality across shared libraries.
* Added capability guards and fixed configuration propagation and resolver allocation.
* Added Diataxis guides, compiled examples and MrDocs API reference.
// end::0.1.0[]
