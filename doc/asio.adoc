= asio: Boost.Asio for native {cpp} and WebAssembly
:toc: left
:toclevels: 1
:idprefix:
:sectanchors:
:example-caption!:
:attribute-missing: warn

`webcpp::asio` makes Boost-style asynchronous {cpp} programs usable in WebAssembly:
Emscripten for browsers, and WASIp2 or WASIp3 for component runtimes such as
Wasmtime. JSPI and Asyncify are separate Emscripten suspension choices.
The capability matrix also distinguishes exceptions, threads and runtime prerequisites.

Native equivalents are actual Boost.Asio types. Wasm selects a versioned
implementation shipped under WebCPP's own headers, using the same source
contract with B2 or another build system. Use `webcpp::asio` consistently for
contexts, executors, timers, sockets and completion tokens. See
<<asio-distribution>> for the compiled runtime sources and dependencies.

In the browser, `io_context::run()` can suspend into the page's event loop.
Browser events wake it, and a configurable handler-count budget offers the
browser opportunities to process other work. A long handler can still block
the page. Native and WASI contexts use their target's reactor instead.

WASIp2 provides single-threaded timers, TCP/UDP, pollable-driven forward DNS,
supplied CLI streams and optional source-built TLS.
See <<asio-wasip2>> for its explicit limitations.
WASIp3 provides timers, TCP/UDP, waitable-driven forward DNS and the same
optional TLS provider, with single-thread and experimental cooperative-thread profiles. See <<asio-capabilities>> for their
limits and the features available in each target variant.

The separate link:{webcpp-libs}/cobalt/{webcpp-page}#cobalt-tutorial[Cobalt library]
uses this executor and operation model for coroutine applications. Its compiled
core, runner and optional SSL wrapper belong to Cobalt, not Asio.

== Find your way through the guide

The guide follows https://diataxis.fr/[Diataxis]: choose a path for what
you need now. All paths share the compiled examples and generated API
reference on this page.

* *Learn by doing:* start with <<asio-quick-start>>.
* *Complete a task:* <<asio-building,build and load a program>>,
  <<asio-run-configure,configure a turn limit>>,
  <<asio-timers-example,schedule and cancel timers>>,
  <<asio-cobalt-build,link a Cobalt program>>, <<asio-wasip3,build for WASIp3>>, or
  <<asio-testing-application,test your application>>.
* *Understand the design:* read <<asio-overview>>, <<asio-run-turn>>,
  <<asio-browser>> and <<asio-allocation-runtime>>.
* *Look up a contract:* use <<asio-capabilities>>, <<asio-names>>, <<asio-guarantees>> and
  the generated <<reference,API reference>>.
